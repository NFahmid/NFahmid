## 🚀 Selected Work

### ◆ EduVision — AI-powered learning platform
*Team project · [FaiyazAwsaf/EduVision](https://github.com/FaiyazAwsaf/EduVision) · top contributor (101 commits)*

Unifies classroom operations for students, teachers, and admins in one platform.

- Automated, rubric-driven answer script evaluation with per-question feedback and manual override
- Real-time tutoring sessions with an AI-powered collaborative whiteboard
- AI-assisted content generation (summaries, worked examples, formula sheets)
- Adaptive learning insights from structured feedback and learning-event tracking
- Tech: Django, React, Supabase (PostgreSQL)

[Live Demo](https://edu-vision-frontend.vercel.app) · [Code](https://github.com/FaiyazAwsaf/EduVision)

### ◆ Multi-Provider Agent Liquidity & Coordination Platform
*Team project · Codex Community Hackathon — bKash presents SUST CSE Carnival 2026*

A fintech prototype helping mobile-financial-service agents monitor shared cash liquidity across providers (bKash, Nagad, Rocket) without blending balances.

- Four independent unusual-activity detectors (velocity spikes, near-identical amounts, balance inconsistency, behavioral k-NN)
- Transparent, confidence-scored liquidity projections
- Alert explanations generated in English, Bangla, and Banglish
- Full case lifecycle: acknowledgement, escalation, review, resolution, immutable audit trail

[Code](https://github.com/A-Piyas-04/SUST-hackathon-onsite)

### ◆ Auto Ledger — AI-assisted personal accounting
*Solo project*

A full-stack double-entry accounting app with an AI assist that turns plain-language transaction descriptions into correctly categorized entries.

- JWT authentication, budget tracking, category-based financial dashboards
- AI transaction assistant for natural-language bookkeeping
- Tech: Node.js/Express, Prisma, PostgreSQL/SQLite, React

[Code](https://github.com/NFahmid/Auto-Ledger)
